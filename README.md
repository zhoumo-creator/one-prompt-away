## ✨ 这是什么

一个慢慢攒起来的 prompt 收藏夹。收录标准很简单：**我用过，觉得好用或好玩**。

- 📌 **每条都有出处**：原作者、原帖或报道链接、什么时候火的
- 🧪 **部分有实测**：标了测试模型和效果截图的，说明我亲手试过
- 🔌 **可以装成 MCP**：在 Claude、Cursor 里用一句话就能找到要用的 prompt

> [!TIP]
> 不知道从哪条开始？先试 [说一件我自己可能不知道的事](prompts/know-myself.md)，30 秒出结果。

**🪞 说一件我自己可能不知道的事**（需要开启 ChatGPT 记忆功能）

根据我们所有的对话，说一件关于我、但我自己可能都不知道的事。

## 🔌 装成 MCP：用一句话找到 prompt

装好之后，直接对 AI 说：

> 💬 「有没有适合营销人写小红书标题的 prompt？」<br>
> 💬 「找一个能帮我认识自己的 prompt」<br>
> 💬 「列出所有生图类的 prompt」

不用重装就能拿到最新内容：仓库一更新，MCP 自动同步。

<details open>
<summary><b>Claude Code</b></summary>

```bash
claude mcp add one-prompt-away -- npx -y github:zhoumo-creator/one-prompt-away
```

</details>

<details>
<summary><b>Claude Desktop / Cursor</b></summary>

在 `claude_desktop_config.json` 或 `~/.cursor/mcp.json` 里加入：

```json
{
  "mcpServers": {
    "one-prompt-away": {
      "command": "npx",
      "args": ["-y", "github:zhoumo-creator/one-prompt-away"]
    }
  }
}
```

</details>

<details>
<summary><b>提供哪些工具</b></summary>

| 工具 | 作用 |
| --- | --- |
| `search_prompts` | 按关键词、分类、人群搜索 |
| `get_prompt` | 取完整卡片和可复制的原文 |
| `list_tags` | 列出所有分类、人群标签和条数 |

</details>
